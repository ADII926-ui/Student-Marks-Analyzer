# Student Marks Analyzer

## 📌 Project Overview
Student Marks Analyzer is a Python-based project that analyzes student marks using the NumPy library. It performs various operations on student marks and generates useful statistical information.

## 🎯 Objectives
- Generate marks for 50 students across 5 subjects.
- Analyze student performance.
- Calculate subject-wise averages.
- Identify the overall class topper.
- Find students who passed and failed.
- Calculate the overall pass percentage.
- Identify the highest and lowest marks.

## 🛠️ Technologies Used
- Python
- NumPy
- Google Colab 

## 📚 Subjects
1. Python
2. Maths
3. English

## ⚙️ Features
- Creation of a 2D NumPy array.
- Display of student marks.
- Identification of students scoring below 40.
- Identification of students scoring above 90.
- Calculation of subject-wise averages.
- Finding the overall topper.
- Calculation of pass percentage.
- Generation of a student marks analysis report.

## 📊 Project Results
- Total Students: 50
- Total Subjects: 5
- Class Average: 66.72
- Highest Marks: 99
- Lowest Marks: 35
- Students Passed: 40
- Students Failed: 10
- Pass Percentage: 80%

## 🚀 How to Run
1. Download the `Student_marks_analyzer.ipynb` notebook.
2. Open it in Google Colab or Jupyter Notebook.
3. Run all the cells.
4. View the student marks analysis and final report.
